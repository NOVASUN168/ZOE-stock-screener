① 这是啥？一句话说清

这是一个本地运行的股票筛选小工具。它把一堆股票按 6 个维度打分（0–100 分），帮你快速看出哪只更"优生优育"、哪只要小心。

它不是荐股软件，也不替你下单。它只把你填（或系统抓）的数据，按固定规则算出一个分数和提醒，决策还是你自己做。

当前里面已经有 15 只真实 A 股（茅台、宁德、比亚迪……），数据来自公开行情接口（详见 ⑥）。

② 怎么打开？

方式 A：在这个工作台里（最简单）

系统已经帮你启动好了。直接点聊天界面里弹出的预览卡片 （地址是 http://127.0.0.1:8765/），就能看到界面。

⚠️ 这个服务器跑在当前这个工作台里。如果关掉或重开会话，它会停。 下次想用，只要跟我说一句"把服务器打开"，我就会再帮你启动。

方式 B：在你自己的电脑上跑（不用依赖工作台）

适合想长期自己用的朋友。两步：

1
先把代码下载到电脑（仓库是公开的）：
git clone https://github.com/NOVASUN168/ZOE-stock-screener.git
然后在文件夹里打开终端。
2
跑两行命令（需要装了 Python 3.8+）：
python scripts/init_db.py
python scripts/server.py
然后浏览器打开 http://127.0.0.1:8765/

④ 怎么新增 / 修改 / 删除一只股票？

➕ 新增一只

在工作台找「+ 新增股票」按钮（通常在表格上方）。会弹出一个表单，填这些就行：

  • 代码 / 名称 / 行业：如 sh600519、贵州茅台、消费/白酒
  • 价格 / PE / PB / ROE / 负债率：从行情软件或本系统抓的数据里抄
  • 技术面 / 资金面：多头/空头、净流入/净流出 等，按你判断选

填完点保存，系统会自动算分，新股票就出现在列表里。

✏️ 修改 / 🗑️ 删除

在列表里点某只股票右边的「编辑」改数据，或点「删除」去掉它。 改完分数会重新算。

小技巧：不会填？先把这 15 只真实股票当"样板"看——点开任意一只， 看它每个字段怎么填的，照着抄格式就不会错。

⑤ 评分咋算的？（通俗版）

系统把一只股票按 6 个维度 打分，加起来就是总分（满分 100）：

分数高 ≠ 一定涨。它只是把"已知信息"量化成一个参考值。 基本面好、估值合理、趋势向上、资金流入的股票，分数自然高。
